# Лаборатория Динамических Систем

Проект строит фазовые траектории, бифуркационные диаграммы и цветные карты
динамических режимов для нескольких дискретных динамических систем.

## Запуск Из Конфига

```bash
python main.py config_henon.json
python main.py config_logistic.json
python main.py config_power_abs.json
```

## Запуск Интерфейса

```bash
python main.py --ui
```

Графический интерфейс позволяет загружать и сохранять JSON-конфиги, выбирать
отображение, переключать векторный и параллельный расчет, менять параметры
системы и строить траектории, карты режимов и бифуркационную диаграмму
логистического отображения.

## Поддерживаемые Отображения

- `henon`: `x(n+1) = 1 - alfa * x(n)^2 - b * y(n)`, `y(n+1) = x(n)`.
- `logistic`: `x(n+1) = r * x(n) * (1 - x(n))`.
- `power_abs`: `x(n+1) = -mu + A|x(n)|^nu + C|x(n)|^(2nu)`.

## Структура Проекта

- `config.py`: загрузка, проверка и сохранение JSON-конфигурации.
- `systems.py`: определения динамических систем.
- `regimes.py`: расчет карт режимов векторным и параллельным способом.
- `plotting.py`: построение и сохранение графиков в PNG.
- `core.py`: объектно-ориентированный слой управления проектом.
- `ui.py`: настольный интерфейс на Tkinter.

## Основные Настройки

- `map`: выбранное отображение: `henon`, `logistic` или `power_abs`.
- `compute_method`: способ расчета карты режимов: `vector` или `parallel`.
- `regime_map.max_period`: максимальный период, который ищется при классификации.
- `regime_map.x_steps` и `regime_map.y_steps`: разрешение карты режимов.
- `transient_steps`: число первых итераций, которые отбрасываются как переходный процесс.
